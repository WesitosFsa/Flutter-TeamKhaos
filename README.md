# Team Khaos Launcher

Aplicación desarrollada en Flutter como proyecto de práctica por Team Khaos, enfocada en la distribución y gestión de videojuegos en formato APK.

Este proyecto simula una plataforma tipo launcher donde los usuarios pueden explorar, descargar e instalar juegos directamente desde la aplicación.

## Caracteristicas

- Descarga de juegos en formato APK

- Instalación directa desde la app

- Catálogo de videojuegos

- Interfaz simple e intuitiva

- Rendimiento optimizado con Flutter


## Tecnologías utilizadas

- Flutter

- Dart

- HTTP / APIs (para descarga de contenido)

- Manejo de almacenamiento local

- Supabase(No ideal pero es a manera de prueba)

- Rendimiento optimizado con Flutter
